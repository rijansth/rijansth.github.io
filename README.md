# Rijan Shrestha — Portfolio

Graphic & multimedia designer based in Dubai: brand identity, packaging, social content, motion graphics, animation, and AI image & video.

**Live:** https://rijansth.github.io

## What's here

| Path | What it is |
| --- | --- |
| `index.html` | The page and its styles |
| `app.js` | Content (projects, case studies, jobs, skills, services) and behaviour |
| `img/` | Project images and the hero character |
| `media/` | Videos and their poster frames |
| `fonts/` | Self-hosted fonts (SIL Open Font License, see `fonts/LICENSES.txt`) |
| `og.jpg` | Preview image shown when the link is shared |

It is a static site: no server, no database, no forms, no trackers, and nothing loads from another domain.
To change text or projects, edit the data at the top of `app.js`.
